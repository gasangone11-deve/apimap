# 어디까지?

OpenStreetMap의 Nominatim에서 실제 장소를 검색하고, 선택한 두 지점 사이의 직선거리를 계산하는 정적 웹 앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 프로젝트 폴더를 Vercel에 가져오면 됩니다. 별도 빌드 단계, 서버, Redis, API 키 또는 환경 변수는 필요하지 않습니다.

## 배포 및 데이터

- Vercel에서 이 저장소를 가져오면 정적 사이트로 배포됩니다.
- 장소 검색은 브라우저에서 OpenStreetMap Nominatim으로 직접 요청합니다. 검색어는 사용자가 검색을 실행할 때만 전송됩니다.
- 계산 결과는 지표면 곡률을 반영한 두 좌표 간 직선거리입니다. `지도에서 보기`를 누르면 선택한 두 위치와 직선거리를 OpenStreetMap 지도 위에 표시하며, 별도의 길찾기 링크도 제공합니다.
- 지도 표시는 Leaflet CDN과 OpenStreetMap 타일을 사용하며 API 키나 환경 변수는 필요하지 않습니다.
- 검색 결과 및 지도 데이터는 © OpenStreetMap contributors입니다. Nominatim의 사용 정책과 요청량 제한을 준수해 주세요. 대규모 또는 상업적 트래픽이 예상되면 적절한 지오코딩 서비스를 사용해야 합니다.
